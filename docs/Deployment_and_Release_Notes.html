2. Fresh installation

1 Clone the repository next to your Odoo 18 addons: 
git clone https://github.com/kamerep/interisV18.git /opt/odoo18-addons/interisV18
2 Copy deploy/odoo18.conf.example to /etc/odoo18.conf, set addons_path, database credentials and a free http_port.
3 Install the suite: 
deploy/deploy.sh -c /etc/odoo18.conf -d mydb --install
4 Optional: install the systemd unit 
sudo cp deploy/odoo18.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now odoo18

3. Upgrading an existing database

1 Back up the database and filestore.
2 Pull the new code and upgrade every suite module: 
git -C /opt/odoo18-addons/interisV18 pull
deploy/deploy.sh -c /etc/odoo18.conf -d mydb
sudo systemctl restart odoo18
Property hierarchy moved. Sub-properties now use property_parent_id. Odoo 18 reserves account.asset.parent_id for gross-increase assets, which feed the parent's book value and depreciation. The 18.0.1.1.0 migration moves existing links automatically; update any custom views, filters or server actions that used parent_id for properties.

4. Running Odoo 18 next to other versions

When Odoo 19 and 20 already use ports 8069 and 8070, run Odoo 18 on 8018 (longpolling 8073). To test the official .deb without installing it system-wide:

dpkg-deb -x odoo_18.0.2024-11-25.deb ~/odoo18ee
ODOO18_HOME=~/odoo18ee deploy/run_local.sh -d property18
The .deb links some web assets (FontAwesome, Roboto, underscore.js) to Debian packages. When unpacking instead of installing, replace those symlinks with real files or install fonts-font-awesome, fonts-roboto-unhinted and libjs-underscore.

5. Testing

deploy/deploy.sh -c /etc/odoo18.conf -d test_db --install --test

The regression tests cover deposit payments and journal entries, property hierarchy isolation from gross-increase assets, weekly rent proration, CRM lead to contract, partner group sync, the rent reminder cron, every wizard report, the commission reports, penalties, recurring maintenance and purchase/sale instalments.

6. What changed in 18.0.1.1.0

Crashes fixed

  • Every payment raised a TypeError (payment journal entry API changed in 18).
  • Deposit buttons used the removed payment field ref (now memo).
  • Converting rent leads, opening their chatter or mail templates failed.
  • Searching booked units failed; un-ticking Tenant/Agent on a contact without a user failed.
  • Several reports failed on multi-property tenancies, missing dates or no state filter.
  • Commission bills failed with an empty currency.

Wrong results fixed

  • Deposit received/returned flags, weekly part-period rent, occupancy rate.
  • Income & expenditure totals (expenses now come from posted vendor bills).
  • Rent voucher balance due; commission owner report; maintenance done notifications.
  • Unbook button never visible and acted on the parent property.
  • Rent reminders: only unpaid rent due in the next 7 days, sent to the tenant without changing the template.

Enabled and improved

  • Commission details and commission invoices reports; Financial Performance Analysis graph.
  • Odoo 18 kanban cards; chatter on commission invoices.
  • App icons redrawn as square, rounded icons that read well in light and dark mode.

7. Follow-ups completed

  • Rent reminder wizard (Tenant Details → Send Rent Reminders) with an overdue-rent template.
  • Daily refresh of occupancy rates; Net Income after maintenance on properties.
  • Full demo scenario for every module — see the Testing Guide.
